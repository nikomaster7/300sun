# 300sun

Direct-booking travel experiences in Valencia: group accommodation, paella workshops, private walks and online language courses.

- `docs/business-plan.md`: services, commissions, phases, open items
- `docs/market-research.md`: platforms, OTA commissions, cruise market, pricing
- `site/`: the website / presentation (minimalist, static)
- `site/images/paella/`: put the real paella photos here
- `docs/site-decisions.md`: how the site was built, photo naming, things to confirm
- `tools/prepare-photos.sh`: resize a photo into the 640/1280/1920 sizes the site uses

Preview locally: open `site/index.html` in a browser. Press **P** for presentation mode.
